Stakeholder briefing · Built with Cursor Cloud Agents + GitHub

Why this exists

The problem we are solving

Before

  • Newcomer follow-up scattered across chats and sheets
  • Hard to see who is assigned and what is overdue
  • Roles and permissions unclear
  • Web, phone, and data not connected

Goal

  • One people-centered Follow-Up system
  • Clear queue → assign → report loop
  • Role-based access for leaders & ministers
  • Same data on web, iOS, and Android

How we work

Delivery workflow

You describe need → Agent builds in GitHub → Pull request review → Merge → Mobile build (EAS) → Web update (optional)

You do not need to code

Request changes in plain language. Review the result. Approve merge when ready.

One codebase

GitHub monorepo: Expo mobile first, plus web, shared rules, Firebase, and docs.

Architecture

One repo — mobile at the center

apps/mobile ★

Primary product. Expo (React Native) for iOS & Android — where ministers and leaders work day to day.

apps/web

Public landing, newcomer registration, and admin/CMS support. Companion to mobile, not the main app.

shared + Firebase

Shared types & RBAC. Auth + Firestore so mobile and web stay on one source of truth.

Same Firebase data on every device. Feature work prioritizes mobile; web follows for public and admin surfaces.

Platforms

Mobile primary — honest status

Mobile — primary target

iOS + Android via Expo is the main product for Follow-Up staff. Scaffold exists; full Follow-Up screens (from Figma) are the next build focus, then TestFlight → App Store / Play.

Web — companion

Public site + registration + CMS patterns already prototyped here. Useful for demos and public entry; not the long-term daily driver for ministers.

Prioritize mobile UI/flows. Reuse shared logic and lessons from the web prototype so we do not rebuild from zero.

End-to-end picture

Ministry workflow we support

Visit / hear about YA → Register online → Enter Follow-Up queue → Leader assigns → Minister follows up → Report & next step

Leaders

See the queue, balance load, manage roles, stay notified.

Ministers

Work assigned people, log contact, keep notes and tasks together.
